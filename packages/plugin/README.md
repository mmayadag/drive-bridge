## Sync Engine Core & SDK

This package is the core of Sync Engine, it contains all the source code of the Sync Engine plugin published on Obsidian plugin directory, as well as the `@hesprs/sync-engine-sdk` package published on npm.

The version of the SDK matches the last Sync Engine version that had API changes. If you see the SDK version lags behind the plugin, it means the API is stable in recent period.

For more about Sync Engine and how to develop a module for it. Refer to [the official website](https://sync.consensia.cc). Or go to [source code repo](https://github.com/hesprs/sync-engine) for deep dive.
